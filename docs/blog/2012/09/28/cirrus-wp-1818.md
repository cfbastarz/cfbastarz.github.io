# Cirrus

Cirrus é uma melodia composta em 2010, já não me lembrava mais dela. É basicamente o mesmo estilo de [Solitude](../../../2010/09/30/hipnoise-solitude-wp-476.md), mas com um andamento diferente. Sobre o nome, Cirrus é uma espécie de nuvem, alta, estratiforme e muito fria. Talvez esta música tenha sido feita em um dia mais frio, não sei, mas gosto dela!
